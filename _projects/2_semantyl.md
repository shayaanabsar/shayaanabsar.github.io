**Semantyl** is an end-to-end Retrieval-Augmented Generation (RAG) system engineered for high-precision question answering across complex heterogeneous document collections.

### Highlights

- **Multi-Format Document Parsing**: Seamlessly processes PDF, DOCX, and TXT files, extracting hierarchical sections, tables, and raw text.
- **Vector Indexing & Similarity Search**: Employs Hugging Face dense embeddings coupled with vector database retrieval to find the most contextually relevant passages for user queries.
- **LangChain Orchestration**: Implements conversational retrieval chains, context compression, and source attribution to eliminate hallucination and provide verifiable citations.
- **Interactive Interface**: Deployed with a responsive Streamlit UI supporting real-time streaming answers, document upload management, and interactive query history.
